# DotFiles

我的各种配置聚集地

## IdeaVIM（Rider / JetBrains ≈ LazyVim）

仓库里的文件：`ideavim/.ideavimrc`  
LazyVim 键位移植：[lazy-idea](https://github.com/cufarvid/lazy-idea)（克隆到 `~/.lazy-idea`）

本机启用：

```bash
ln -sf ~/Codes/DotFiles/ideavim/.ideavimrc ~/.ideavimrc
git clone https://github.com/cufarvid/lazy-idea.git ~/.lazy-idea
```

Rider Marketplace 还需要：IdeaVim、IdeaVim EasyMotion、Which-Key（`idea-which-key`）。改完后状态栏 IdeaVIM → Reload。
